# SS-27 / Topol-M

`model.ts` generates an illustrative exterior in native Three.js. Eight visual
sections can be separated using the viewer's explode button. Proportions, surface
markings, section breaks, and movements are artistic choices in arbitrary units.

The name refers to SS-27 Mod 1 / Topol-M. Identification reference:
https://missilethreat.csis.org/missile/ss-27/
