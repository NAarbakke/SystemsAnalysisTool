# Civilian turbofan display model

A two-spool high-bypass cutaway for the Assembly explorer, with fourteen selectable modules: spinner, fan, fan case, outlet guide vanes, booster, nine-stage high-pressure compressor, core casing, annular combustor, two-stage high-pressure turbine, five-stage low-pressure turbine, low-pressure shaft, exhaust, nacelle and accessory gearbox. All geometry uses arbitrary display units. Blades are lofted airfoil-like sections for appearance only, not aerodynamic or manufacturing geometry. This model supplies component names and roles; material specifications and operating data are intentionally unspecified.

The separation slider spreads the sections for inspection and restores their original positions at zero. The model is available only in the Assembly picker.
