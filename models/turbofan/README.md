# Civilian turbofan display model

A stylized Three.js cutaway for the Assembly explorer, with ten selectable sections. All geometry uses arbitrary display units. Blades and internal sections are simplified visual symbols, not aerodynamic or manufacturing geometry. This model supplies component names and roles; material specifications and operating data are intentionally unspecified.

The separation slider spreads the sections for inspection and restores their original positions at zero. The model is available only in the Assembly picker.
