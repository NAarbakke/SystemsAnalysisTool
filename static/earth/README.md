# Offline Earth imagery

NASA Blue Marble Next Generation, July 2004, with topography and bathymetry.

Source image (21600 × 10800):
https://eoimages.gsfc.nasa.gov/images/imagerecords/73000/73751/world.topo.bathy.200407.3x21600x10800.jpg

Source SHA-256: `D225F1F35A6448A4D1D8F6DE6E48F3433E470085B70A35800E64F384F269A7B0`

Credit: NASA Earth Observatory / Blue Marble Next Generation. This is historical satellite-derived imagery, not live imagery. NASA imagery use guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/ .

Generated by `scripts/tile-earth.ps1` from the source downloaded into `work/map-source/blue-marble.jpg`. The processing resamples and tiles the source without adding invented detail. No download is performed at build time or runtime.

Geographic XYZ scheme (WGS84 longitude/latitude): `{z}/{x}/{y}.jpg`, 256-pixel tiles, north-origin rows, 2×1 tiles at level zero. Levels 0–5 contain 2,730 tiles, with maximum equivalent coverage 16384×8192 pixels. This is 8× the linear resolution and 64× the pixel count of the previous bundled 2048×1024 Natural Earth map. Terrain remains a smooth ellipsoid.

Keep this directory with the deployment. The originals are public NASA imagery; this derived tile pyramid is served entirely locally.
